# DragOrbit

Shared source packages for DragBizz web applications and Desktop.

- `ui/`: React controls, overlays and tables.
- `core/`: themes, tokens and API helpers.
- `features/`: shared business screens and feature contracts.
- `screens/`: screen workspace foundation.

Host applications provide routing, authentication, data access and persistence. Consumers link to package folders and compile the shared source in their own build.

See [SETUP.MD](SETUP.MD) for setup.
